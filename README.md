# Web Development ABL

Three beginner-friendly case studies selected from the Web Development Activity-Based Learning assignment.

## Selected projects

1. **Personal Portfolio Website** — profile, education, technical skills, hobbies, projects and contact form.
   - [Open website source](01-personal-portfolio/index.html)
   - [Project details](01-personal-portfolio/README.md)
2. **Bakery and Cake Shop Website** — cake and pastry products, sample prices, category filters, demo shopping bag and enquiry form.
   - [Open website source](02-bakery-cake-shop/index.html)
   - [Project details](02-bakery-cake-shop/README.md)
3. **Fitness Center and Gym Website** — workout programs, trainer profiles, membership plans, class schedule and enquiry form.
   - [Open website source](03-fitness-center-gym/index.html)
   - [Project details](03-fitness-center-gym/README.md)

## Technologies
HTML5, CSS3 and beginner-level JavaScript. Each project is a self-contained webpage with responsive styling and interactive features.

## How to run
Open the project's `index.html` file in a web browser. No installation or server is required.

## Customization before submission
Update the sample profile, educational details, project information, business address, contact details, trainer information and prices as needed.

## Important
These are front-end academic demonstrations. The forms only display confirmation messages; they do not send data to a server. Bakery bag count is a browser demonstration and does not process real orders. Membership enquiries do not create real bookings.
