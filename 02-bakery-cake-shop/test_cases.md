# Test Cases — Bakery and Cake Shop Website

Run each test by opening `index.html` in a modern web browser. Record the actual result and mark Pass/Fail after manual verification.

| Test ID | Test steps / input | Expected result | Acceptance check |
|---|---|---|---|
| TC01 | Open index.html | Bakery home page and menu link display | Pass if Sweet Crumbs heading and Explore the Menu are visible. |
| TC02 | Click Cakes filter | Only cake products remain visible | Pass if Strawberry Dream Cake and Chocolate Truffle display. |
| TC03 | Click Pastries and Cookies filters | Only products in the selected category display | Pass if matching cards appear and other categories are hidden. |
| TC04 | Click Add to bag on a product | Demo bag count increases by one | Pass if the displayed item count increments. |
| TC05 | Submit enquiry form with required fields empty | Browser required-field validation appears | Pass if the form is not submitted. |
| TC06 | Enter name and celebration then submit | A demo thank-you response appears | Pass if the response appears; no order or message is sent. |
| TC07 | Resize browser to a mobile width | Hero, product grid and contact layout adapt | Pass if the page remains readable. |
