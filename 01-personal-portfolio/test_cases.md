# Test Cases — Personal Portfolio Website

Run each test by opening `index.html` in a modern web browser. Record the actual result and mark Pass/Fail after manual verification.

| Test ID | Test steps / input | Expected result | Acceptance check |
|---|---|---|---|
| TC01 | Open index.html | Home page and introduction are visible | Pass if title, profile introduction and Explore My Work link appear. |
| TC02 | Click About, Education, Skills, Projects and Contact | Each navigation link reaches its section | Pass if the matching section is brought into view. |
| TC03 | Open the Skills section | HTML5, CSS3, Python, JavaScript and Problem Solving chips display | Pass if all five skill chips are visible. |
| TC04 | Submit the contact form with all fields empty | Browser required-field validation appears | Pass if the form is not submitted. |
| TC05 | Enter a valid name, email and message, then submit | A demo thank-you response appears and fields reset | Pass if the response appears; no message is actually sent. |
| TC06 | Resize browser to a mobile width | Navigation and hero content adapt to a narrow screen | Pass if content remains readable without horizontal page overflow. |
